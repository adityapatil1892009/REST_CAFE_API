# Cafe REST API ☕

A simple REST API built using Python, Flask, and SQLite to manage cafe information. The API lets users explore cafes, search by location, add new cafes, update coffee prices, and delete cafe records using an API key.

I built this project to understand how REST APIs work in practice, how different HTTP methods are used, and how a Flask application communicates with a database.

## Features

- **Get all cafes** — Retrieve the complete list of cafes.
- **Get a random cafe** — Fetch a randomly selected cafe.
- **Search by location** — Find cafes in a particular location.
- **Add a cafe** — Store new cafe details in the database.
- **Update coffee price** — Change the coffee price of a specific cafe.
- **Delete a cafe** — Delete a cafe record with API key authorization.

## Tech Stack

- **Language:** Python
- **Backend Framework:** Flask
- **Database:** SQLite
- **API Testing:** Postman
- **Environment Variables:** python-dotenv
- **Deployment:** Render
- **Server:** Gunicorn
